# Router Has No Lights At All (Appears Completely Off)

If none of the lights on your NovaLink router are on, this is a power issue, not a network issue.

## Steps to resolve
1. Confirm the power adapter is firmly plugged into both the router and the wall outlet.
2. Try a different wall outlet to rule out a dead socket.
3. Check the power adapter for visible damage (frayed cable, bent pins).
4. If you have a spare compatible power adapter, test with it.
5. Hold the reset button on the back of the router for 10 seconds — if the router powers on but resets to factory settings, this confirms the power supply is fine and the issue was a software freeze.

## When to escalate
If the router shows zero signs of life after trying a different outlet and a known-working adapter, the router hardware has likely failed. Escalate to **Network Operations** to arrange a replacement unit.
