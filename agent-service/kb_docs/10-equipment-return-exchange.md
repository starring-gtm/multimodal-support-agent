# Returning or Exchanging Equipment

## When a return is required
- After plan cancellation (router and ONT box must be returned within 14 days)
- After a router replacement due to hardware failure (old unit must be returned within 14 days of receiving the replacement)

## Steps to arrange a return
1. Generate a prepaid return shipping label from the account portal under Equipment > Return Device, or request one via support.
2. Package the router and power adapter (ONT box return instructions differ — see below).
3. Drop off at any listed carrier location within 14 days.
4. Tracking is automatically linked to the account; once received, any pending equipment fee hold is released.

## ONT box returns
The ONT box is typically wall-mounted and professionally installed. Customers should **not** attempt to remove it themselves — a technician visit is required to retrieve it, at no cost to the customer.

## When to escalate
If a customer disputes an equipment fee, claiming they returned the device but tracking shows no delivery, escalate to **Logistics** to investigate the shipment.
