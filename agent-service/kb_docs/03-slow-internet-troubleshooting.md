# Internet Is Slower Than Expected

Slow speeds can come from several sources: your plan tier, Wi-Fi interference, device load, or a network-side issue.

## Steps to resolve
1. Run a speed test with a device connected directly via Ethernet cable (not Wi-Fi) to isolate whether the issue is wireless interference.
2. Compare the result against your plan's advertised speed (check your plan tier in account settings).
3. If wired speed matches your plan but Wi-Fi is slow:
   - Move closer to the router.
   - Check for interference from other electronics (microwaves, cordless phones, neighboring Wi-Fi networks on the same channel).
   - Restart the router.
4. If wired speed is significantly below your plan's advertised speed (more than 30% lower), this indicates a network-side issue.
5. Check how many devices are connected — heavy simultaneous usage (streaming, gaming, large downloads) across many devices can reduce per-device speed even when total throughput is normal.

## When to escalate
If wired speed test results are consistently more than 30% below the plan's advertised speed across multiple tests and times of day, escalate to **Network Operations** for a line quality check.
