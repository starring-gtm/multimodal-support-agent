# Changing Your Plan (Upgrade or Downgrade)

## How plan changes work
- **Upgrades** take effect immediately. The customer is charged a prorated amount for the remaining days in the current billing cycle at the new plan's rate.
- **Downgrades** take effect at the start of the next billing cycle, to avoid partial-refund complexity. No proration is applied.
- Plan changes can be made from the account portal under Plan > Change Plan, or by contacting support.

## Common questions
- **"Why wasn't I refunded for the difference after downgrading?"** — Downgrades intentionally apply at the next cycle rather than mid-cycle, so no refund is generated; this is expected behavior, not an error.
- **"Can I switch back if I don't like the new plan?"** — Yes, plan changes can be reversed at any time, following the same upgrade/downgrade timing rules above.

## When to escalate
If a customer requests a retroactive proration adjustment for a downgrade (an exception to standard policy), escalate to **Billing** for manager approval.
