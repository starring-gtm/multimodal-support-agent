# Setting Up a New NovaLink Router

## Steps
1. Connect the fiber cable from the ONT (Optical Network Terminal) box to the WAN/Internet port on the router (usually a distinct color, often blue).
2. Plug in the router's power adapter and wait for the power light to turn solid (usually 60-90 seconds).
3. Wait for the "Internet" or "WAN" light to turn green or blue, indicating a successful connection.
4. Connect a device to the default Wi-Fi network. The default network name (SSID) and password are printed on a sticker on the bottom of the router.
5. Open a browser and navigate to the setup address printed on the sticker (typically a local IP like 192.168.1.1) to customize the network name and password.

## Expected light sequence during first setup
Power light solid → Internet/WAN light blinking → Internet/WAN light solid → Wi-Fi light on. The full sequence typically completes within 3-5 minutes of first power-on.

## When to escalate
If the Internet/WAN light never turns solid after 10 minutes and the fiber cable is confirmed properly connected, escalate to **Network Operations** — this may indicate the line has not yet been activated on our end.
